# Day 21: Missing Value Analysis using Pandas

## 📌 Project Overview

This project focuses on identifying and analyzing missing values in a dataset using Python and Pandas. It helps us understand incomplete data before using it for data analysis or machine learning.

## 🎯 Objective

* Identify missing values in a dataset.
* Count missing values in each column.
* Calculate the percentage of missing values.
* Create a missing-value summary.
* Identify columns that may require data treatment.

## 🛠️ Tools Used

* Python
* Pandas
* Jupyter Notebook

## 📊 Dataset

A sample student dataset containing the following columns:

* Name
* Age
* Marks
* City

The dataset contains missing values represented by `None`.

## 💻 Concepts Learned

* Creating a Pandas DataFrame.
* Using `isnull()` to identify missing values.
* Using `sum()` to count missing values.
* Calculating missing-value percentages.
* Creating a summary table.
* Identifying columns that require missing-data treatment.

## 📈 Results

| Column | Missing Values | Missing Percentage |
| ------ | -------------: | -----------------: |
| Name   |              0 |                 0% |
| Age    |              2 |                40% |
| Marks  |              1 |                20% |
| City   |              1 |                20% |

**Total missing values:** 4

## ✅ Conclusion

Through this task, I learned how to identify and count missing values using Pandas. I also learned to calculate missing-value percentages and identify columns that may require data cleaning.

This task helped me understand an important step in data preprocessing before machine learning.
